## 🌌 Manifesto & About Me / Hakkımda

**EN:**  
I am **Onur Aksoy** (widely recognized across developer ecosystems and systems research publications as **Hackonomist**). Based in Ankara, Turkey, and operating globally, I work as a **Software Developer, Digital Strategist & Systems Architect** focused on algorithmic memory integrity, sovereign data governance, deterministic multi-agent orchestration, and offline-first local systems.

### ✍️ Yeni Proje Ekleme Rehberi (`src/content/projects/<slug>.json`)
Portfolyoda sergilenen tüm amiral gemisi projeler Astro Content Collections altında bağımsız JSON dosyaları (`src/content/projects/*.json`) olarak yönetilir ve derleme anında Zod şemasıyla doğrulanır:
1. `src/content/projects/<slug>.json` adında yeni bir dosya oluşturun.
2. Proje nesnesini JSON olarak tanımlayın:
   ```json
   {
     "id": "yeni-proje",
     "slug": "yeni-proje",
     "order": 4,
     "featured": true,
     "accentColor": "#C58A3A",
     "tags": [".NET 8", "PostgreSQL", "Tailwind"],
     "links": {
       "live": "https://...",
       "store": "https://..."
     },
     "metrics": {
       "en": [{ "label": "Latency", "value": "< 10ms" }],
       "tr": [{ "label": "Gecikme", "value": "< 10ms" }]
     },
     "en": {
       "title": "Project Title",
       "description": "Short summary",
       "role": "Lead Architect",
       "period": "2024 — Present",
       "status": "Production",
       "executiveOverview": "...",
       "mermaidTopology": "flowchart LR ...",
       "benchmarks": { "title": "...", "headers": [], "rows": [] },
       "sections": [],
       "techStack": []
     },
     "tr": {
       "title": "Proje Başlığı",
       "description": "Kısa özet",
       "role": "Sistem Mimarı",
       "period": "2024 — Günümüz",
       "status": "Üretimde",
       "executiveOverview": "...",
       "mermaidTopology": "flowchart LR ...",
       "benchmarks": { "title": "...", "headers": [], "rows": [] },
       "sections": [],
       "techStack": []
     }
   }
   ```
3. Arama sonuçları için `tr`/`en` bloklarına kısa `seoTitle` (≤ 47 karakter) ve `seoDescription` (110–160), kök seviyeye `schema` (`applicationCategory`, `operatingSystem`) ekleyin; ardından `npm run og:images` ile proje paylaşım kartlarını üretin.
4. `npm run build` komutu ile tip güvenliğini, statik derlemeyi ve SEO/GEO koruma kapısını doğrulayın.

### ✍️ Yeni Yayın Ekleme, Kapak Görselleri ve Vitrin (`src/content/broadcasts/`)
Tüm yayınlar (Video, Podcast, Makale vb.) `src/content/broadcasts/{en,tr}/*.md` dizininde Markdown olarak tutulur.
- **Kapak Görseli:** Frontmatter'a `thumbnail: '/images/broadcasts/<ad>.webp'` eklenmesi yeterlidir. Video yoksa sayfada 16:9 sinematik obsidian hero görseli ve OpenGraph/JSON-LD kartı olarak otomatik devreye girer.
- **Akademik DOI, Kanonik PDF & Google Scholar Entegrasyonu:** Frontmatter'a `doi` ve `scholarlyPaper` eklendiğinde `BroadcastJsonLd.astro` derleme anında otomatik `ScholarlyArticle` (`encoding` PDF dahil) ve DataCite DOI `PropertyValue` üretir; `/en/broadcasts/<slug>/` sayfalarında Highwire Press `citation_*` meta etiketleri basılır ve `check-seo.mjs` (`K12`, `K13b`) doğrular.
- **Otomatik Vitrin:** Yeni bir yayın eklendiğinde hem `/broadcasts/` sayfalarında listelenir hem de `LatestBroadcasts.astro` sayesinde ana sayfa vitrininde otomatik ilk 5'e yerleşir.
